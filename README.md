## 💻 Menjalankan Proyek Portofolio Secara Lokal

Proyek ini dibangun menggunakan web statis modern (**HTML5**, **Vanilla CSS**, dan **Vanilla JavaScript**) tanpa dependensi build tools yang berat.

### Menjalankan Server Lokal:

```bash
# Opsi 1: Menggunakan PHP (Rekomendasi)
php -S localhost:8000

# Opsi 2: Menggunakan Python 3
python3 -m http.server 8000

# Opsi 3: Menggunakan Node.js / Live Server
npx live-server
```

Akses melalui browser di: `http://localhost:8000` (atau port yang tertera pada terminal).
